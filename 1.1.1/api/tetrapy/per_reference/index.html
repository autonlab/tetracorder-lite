    Per reference

    source module tetrapy.per_reference

    Per-reference outputs for group 2: every group 2 reference's own fit, depth and fd at every pixel.

    EDITED 11/24/2027: new module (optional per_reference pipeline stage).

    Why this is needed#

    Within a group, Tetracorder computes the fit and depth of every enabled reference at every pixel, then keeps only the group's best reference and sets every other reference of the group to 0 before the images are written (tp1all.r). A normal run therefore gives, per pixel, the winner of group 2 and zeros for the other 199 references. A reference that is alone in its group is always that group's best, so its own values are written wherever its own rules pass.

    What this stage does#

    The Tetracorder program is not changed. After the setup stage has made the run folder (output.tetracorder), this stage:

    1. copies the run folder once per batch of group 2 references;
    2. in each copy, edits the run folder's copy of the expert-system command file (cmd.lib.setup.t6.00a6): each batch reference moves from group 2 to a free group number of its own, and the header is extended so Tetracorder accepts those groups (see :func:regroup); the new group numbers are switched on in DISABLE/force-disable.txt;
    3. starts Tetracorder in each copy the way the run folder's cmd.runtet starts it (<ptc> r1 reading <tetcmdsstart>), without cmd.runtet's picture-making steps;
    4. collects, for every group 2 reference, the .fit, .depth and .fd images Tetracorder wrote (gzip-compressed, bytes unchanged), and stacks the fd images into one ENVI cube with one band per reference.

    Two modes#

    Tetracorder allows 50 groups (multmap.h: maxgrp=50); the stock command file uses 22 group numbers, so 28 are free.

    lean (default; used for the EMIT-AV5 group 2 fd labels) Each run takes up to 28 references (8 runs for the 200 of group 2). Every entry that the batch does not need is switched off with its own use= no. Kept on: the batch references, and every entry that one of their NOT tests refers to (followed through the entries those refer to in turn), so each NOT test compares against the same reference as in a normal run. A referenced entry of group 0 is moved into group 2 (where it competes with nothing written out), so no group 0 entry competes with the batch. conservative Nothing is switched off or moved except the batch references, which go to free group numbers that are also listed on the nogroup0: line (so group 0 does not compete with them). That line has 80 columns, so one run takes at most 19 references (11 runs). Much slower, because every entry of the file runs; it exists to check that lean gives the same numbers.

    Images are read as Tetracorder writes them (cublineout.r, creatoutfiles.r): one unsigned byte per pixel after a label of whole records (at least 299 bytes); fit is stored as fit x 255, depth and fd as value x 255 / X, where X is the reference's 8 DN 255 = X setting (column depth_value_of_255 of the reference table).

    source run(tetracorder: str, output: str, rfl: str, mode: str = 'lean', jobs: int = 1, keep_runs: bool = False) → dict

    Run Tetracorder once per batch of group 2 references, each reference alone in its own group, and collect every reference's fit, depth and fd images plus a stacked fd cube.

    Parameters

    • tetracorder : str — The run folder made by the setup stage (output.tetracorder); it is copied, never changed.

    • output : str — Folder for the results (must be empty or absent): group2/<name>.{fit,depth,fd}.gz, group2_fd + group2_fd.hdr (ENVI, uint8, BIP, band k = group 2 reference k in command-file order), group2_references.csv, summary.json, logs/<run>/.

    • rfl : str — The scene reflectance (data file); its header supplies samples, lines, map info and coordinate system string.

    • mode : {"lean", "conservative"} — See the module docstring.

    • jobs : int — Tetracorder runs at the same time.

    • keep_runs : bool — Keep the per-batch run folders (output/runs/<mode>_<first>) after collecting.

    Raises

    • FileExistsError

    • RuntimeError
